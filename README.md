# Pet Portal Management System (C++)

## Project Description

Designed and implemented a console-based **Pet Portal Management System using C++** with Object-Oriented Programming principles, STL, File Handling, and Input Validation.

The application was developed to manage pet and owner information through a structured and menu-driven system. It allows users to register pets, search records, update pet information, delete records, view all registered pets, sort pet data, and generate basic statistics.

The project follows a modular multi-file C++ structure by separating pet data management, file operations, validation, and portal functionalities into different classes.

---

## Problem Statement

Managing pet information manually can become difficult when maintaining multiple records containing pet details, vaccination information, and owner contact information.

Manual records may also result in duplicate IDs, invalid information, difficulty searching for a particular pet, and challenges while updating or deleting existing records.

This project provides a simple console-based solution for efficiently managing pet records while maintaining persistent data using File Handling.

---

## Solution Approach

- Designed separate classes for Pet Management, Portal Operations, File Management, and Input Validation.
- Applied Object-Oriented Programming principles to organize the application into reusable modules.
- Used STL Vector to dynamically manage collections of pet objects.
- Implemented File Handling to store and retrieve pet records persistently.
- Implemented CRUD operations for managing pet information.
- Added duplicate Pet ID detection to maintain unique records.
- Implemented input validation for important user inputs.
- Used STL sorting techniques to organize pet records.
- Added statistical analysis for stored pet information.

## Results

Successfully developed a modular console-based **Pet Portal Management System in C++** for managing pet and owner records.

Implemented complete CRUD operations including pet registration, viewing, searching, updating, and deletion.

Pet information is stored persistently using File Handling so that records remain available after restarting the application.

Pet records can be sorted using STL algorithms and displayed using a structured table format.

Basic statistics are generated from the stored pet records including vaccination counts, gender counts, average age, and average weight.

The project follows a modular multi-file C++ structure with separate classes for Pet, Portal, File Management, and Validation.
